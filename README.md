# ZasDict for Windows

イジェール語用ローカル辞書ソフト ZasDict の Windows 版。C# / .NET 8 / WPF 製。
OBS で画面を配信しながら編集することを前提に、ダイアログやメニューをすべてメインウィンドウ内に描いています。

## 主な機能

- OTM-JSON 辞書の閲覧・検索・編集（未知のフィールドは保ったまま書き戻す）
- 例文の管理と ZpDIC Online への照会
- 関連語の対照登録の自動反映、更新履歴 CSV の記録
- GitHub 上の辞書を読み込み・コミットする GitHub モード
- 方言変換、IPA → 綴り、統計、凡例の表示・編集
- 枠の分割とタブの持ち運びで自由に組める画面、タブの独立ウィンドウ化
- 配信用の単語ウィンドウ・単語数ウィンドウ、埋め込みブラウザ（WebView2）
- Heksa フォントによるイジェール文字表示

## OBS で映す

1. ソースに［ウィンドウキャプチャ］を追加し、`ZasDict for Windows` を選ぶ
2. 単語や語数を別枠で見せる場合は、ヘッダの［ウィンドウ］から単語ウィンドウ・単語数ウィンドウを開き、
   それぞれ［ウィンドウキャプチャ］で `ZasDict 単語ウィンドウ` `ZasDict 単語数ウィンドウ` を選ぶ
3. 切り抜くなら、設定 → 単語ウィンドウ で背景色を `#00B140` にして OBS 側でクロマキーを掛ける（2 つの窓で共通）
4. 持ち出したタブの独立ウィンドウは本体のキャプチャに映らない。本体の枠に戻すか、
   `ZasDict 統計` のような題の窓を別ソースとして選ぶ

ファイルダイアログ（開く／保存／フォント選択）は OS のウィンドウなので配信には映りません。

## 必要なもの

- .NET 8 デスクトップランタイム（自己完結ビルドなら不要）
- WebView2 ランタイム（ブラウザ機能のみ。Windows 10 以降ならほぼ Edge に同梱）
- Heksa フォント `Fazik-regular.ttf`（任意。リポジトリには含まない。設定 → 表示・動作 から取り込む）

## ビルド

.NET 8 SDK が必要です。

```
dotnet build ZasDictWin.sln -c Release
dotnet test ZasDictWin.sln
dotnet publish ZasDictWin.csproj -c Release
```

配布用の exe、成果物の削除などは [開発者向け](docs/development.md) を参照。
