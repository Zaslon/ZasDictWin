# 使い方

## 画面の配置

画面は「枠（タブ束）」と「枠を 2 つに割る境目」の入れ子だけでできている（Blender の画面分割と同じ考え方）。
既定は左に検索、右に単語詳細。

- 検索・単語詳細・ブラウザ・ツール類・エディタ・設定など、画面はすべて 1 枚のタブ。
  同じ枠に入れたものはタブで切り替わり、別々の枠に分ければ同時に見える
- 検索と単語詳細は閉じられないが、どの枠へも運べる
- タブは非モーダル。開いたまま検索・一覧・詳細を操作できる

| 操作 | やり方 |
| --- | --- |
| 枠を割る | 枠の四隅のつまみを掴み、枠の内側へ引く。できる側が着色される。できた枠は空で、タブを運び込むまで［枠を閉じる］を出す |
| 枠を結合する | 四隅のつまみを隣の枠へ引く。消える側が着色され、中のタブは残る枠へ移る |
| 枠の大きさを変える | 境目をドラッグ |
| タブを並べ替える | 見出しを掴んで同じ枠のタブ列の上で左右へ動かす。動かしている間に並びが入れ替わる |
| タブを運ぶ | 見出しを掴んで別の枠の真ん中で離す。運び出した元の枠の端（上端はタブ列のすぐ下）へ寄せて離すと、その辺に新しい枠を割り出してから入れる |
| 独立ウィンドウにする | タブをアプリのどの窓にも掛からない場所まで運んで離す。本体の枠へ運び戻せばタブに戻る |

- 取りやめは Esc（並べ替えも元の並びに戻る）。窓の中で枠を外して（ヘッダやフッタの上で）離したときは動かない
- 割った先が 140px より細くなる分割はできない
- 最後のタブを閉じて空になった枠は隣へ吸収される（分割で作った空の枠だけはそのまま残る）
- 独立ウィンドウの中も同じ割り付けなので、枠を割ったり、窓から窓へ運んだりできる。
  窓を閉じると中のタブも閉じる（検索・単語詳細だけは本体へ戻る）。確認ダイアログは常に本体に出る
- 割り付け（枠の入れ子・取り分・タブの置き場所と並び・独立ウィンドウの位置と大きさ）は `settings.json` に残る。
  閉じたタブも次に開くと同じ枠に出る（並びの中では末尾に付く）
- 同じ種類のタブは 1 枚まで。開いている種類のボタンとショートカットは無効になる。
  単語エディタか例文エディタを開いている間は［開く］［新規辞書］も止まる（保存先が別の辞書にすり替わるのを防ぐため）

ウィンドウは標準のタイトルバーを持たない。上端のタイトル行（とメニューバーの空いた部分）をつかんで移動、
ダブルクリックで最大化する。未保存はタイトル行の辞書名の横のドットと「未保存」で示す。

## メニューバー

タイトル行の下にメニューバーがあり、全ての機能をここから実行できる。右側のボタン（GitHub の読み込み・コミット、
単語を追加、例文、ブラウザ）は同じ操作の近道。

- **ファイル(F)**: 開く…・辞書を新規作成・上書き保存・名前を付けて保存…・（GitHub モードのとき）GitHubから読み込む・GitHubにコミット…・終了
- **編集(E)**: 元に戻す・やり直し（下の「元に戻す・やり直し」を参照）、単語を追加…・単語を編集…・単語を複製・単語を削除（選択中の単語）、検索（検索欄へ移る）
- **表示(V)**: 表示の設定…（下の「表示の設定」）、文字を大きくする・文字を小さくする、ブラウザ
- **ツール(T)**: 例文・変換（方言）・IPA → 綴り・統計・凡例・更新履歴。置き場所を覚えていないうちは独立ウィンドウで開く。
  開いているときに選び直すとそのタブを表に出す
- **ウィンドウ(W)**: 配信用の単語ウィンドウ（選択中の単語を大きく表示）と単語数ウィンドウ（総語数を `1234語` の形で表示。
  検索の絞り込みには連動しない）。背景色・文字サイズ倍率・最前面・訳語や内容の表示可否は 設定 → 単語ウィンドウ
  （→ [OBS で映す](../README.md#obs-で映す)）
- **設定(S)**: 設定…
- **ヘルプ(H)**: 使い方（この文書をブラウザで開く）・バージョン情報

項目名の末尾の「…」は、選ぶとさらに入力を求める画面（ファイルの選択・エディタ・コミットメッセージ）が開くことを示す。
ショートカットのある項目は、右端にそのキーを示す。

ブラウザは WebView2 のタブ。アドレス欄で Enter、URL でない語句は Google 検索。開始 URL と起動時に開く可否は
設定 → ブラウザ。

凡例は［編集］でその場で書き換えられる。`legend` が文字列か未設定なら Markdown、構造化 JSON なら JSON のまま編集する。

## 単語と例文の編集

- ［単語を追加］、一覧の「⋯」、詳細画面のボタンから追加・編集・複製・削除。追加時は検索欄の文字列が見出し語の初期値になる
- 単語・例文・凡例のエディタを、書きかけの変更を残したまま閉じようとすると（［キャンセル］、タブの ×、Esc、
  独立ウィンドウを閉じる）、「保存せずに閉じる」「編集を続ける」を確認する
- 関連語は追加・削除とも相手側に対照の関係が自動で入る。見出し語の変更は参照側にも波及し、削除時は被参照を外す
- 単語詳細の見出し語・タグ・訳語・変化形・内容は選んで Ctrl+C でコピーできる
- ［例文］で例文の一覧・検索・追加・編集・削除。出典が「自作」以外なら ZpDIC Online に番号で照会して訳と補足を引ける
  （API キーの置き場所は [データと設定ファイル](data.md#設定ファイルと秘密情報)）
- 保存が成功するたびに `<辞書名>_changelog.csv` に更新履歴を追記する。ツール → 更新履歴 で一覧、CSV の差し替えと書き出しができる。
  追記に失敗したときはダイアログで知らせ、書けなかった履歴は次の保存で書き直す。書けていない履歴を残したまま終了しようとすると確認する

## 元に戻す・やり直し

単語の追加・編集・複製・削除、例文の追加・編集・削除、凡例の編集、辞書依存設定の変更を、編集 → 元に戻す（Ctrl+Z）で
1 つずつ取り消し、やり直し（Ctrl+Y / Ctrl+Shift+Z）で戻せる。

- 関連語の対照登録や見出し語の変更の波及など、その操作で書き換わった他の単語も一緒に戻る
- 取り消した操作の更新履歴は、まだ CSV に書いていなければ取り下げ、書いた後なら逆向きの行（削除を戻したなら ADD）を足す
- エディタを開いている間は使えない。入力欄の中の Ctrl+Z / Ctrl+Y は、その入力欄の打ち直しに使われる
- 履歴は別の辞書を開く・新規辞書を作ると消える

## GitHub モード

設定 → GitHub で、辞書の編集元を「ローカル編集」と「GitHub」から選ぶ。GitHub モードでは自動保存が無効になり、
書き込みは［コミット］に一本化される。

- 対象は 1 リポジトリ・1 ブランチ・辞書 JSON 1 本・更新履歴 CSV 1 本（owner/repo/ブランチ/パスを設定で指定）
- ローカルの作業ファイルは開いている辞書そのもの。辞書を開いていないときだけ
  `%APPDATA%\ZasDictWin\github\<owner>__<repo>__<branch>\` に作る。
  更新履歴 CSV は設定で選んだ CSV、未選択なら辞書と同じ場所の `<辞書名>_changelog.csv`。
  辞書を開いていないとき（`%APPDATA%` 下の作業コピーを使うとき）は、設定の CSV ではなく常に作業コピーと同じ場所の
  `<辞書名>_changelog.csv` に置く。
  開いている辞書ファイルのフルパスは、編集モードによらず設定 → GitHub の先頭に出る
- ［GitHubから読み込む］: JSON と CSV を取得してローカルと比べ、どちらかに差があれば上のファイルへ上書き（無ければ作成）して
  読み込み直す。上書き・作成の前に、対象のファイルごとに「上書き先」「作成先」を示して確認を挟む。両方とも差が無ければ確認は出ない
- ［コミット］: 未保存なら先に保存し、辞書と更新履歴を 1 回のコミットで送る。メッセージは保留中の更新履歴から
  自動生成され、送信前に書き換えられる
- 他所が先にブランチを進めていた場合はコミットが弾かれる。［GitHubから読み込む］で最新化してからやり直す

## キーボード

| キー | 動作 |
| --- | --- |
| Alt / F10 | メニューバーへ移る（もう一度押すと元の場所へ戻る）。左右の矢印でメニューを、Enter・↓で開き、上下の矢印で項目を選ぶ。開いた一覧では項目の括弧の文字でも選べる |
| Alt+文字 | そのメニューを開く（Alt+F でファイル、Alt+E で編集、Alt+V で表示、Alt+T でツール、Alt+W でウィンドウ、Alt+S で設定、Alt+H でヘルプ） |
| Ctrl+O / Ctrl+S / Ctrl+Shift+S | 開く / 上書き保存 / 名前を付けて保存 |
| Ctrl+Z / Ctrl+Y・Ctrl+Shift+Z | 元に戻す / やり直し |
| Ctrl+Enter / Ctrl+N | 検索欄の文字列を見出し語にして単語を追加 |
| Ctrl+E / Ctrl+D | 選択中の単語を編集 / 複製 |
| Ctrl+F | 検索欄へ移る |
| Esc | 上の層から 1 枚ずつ畳む（メニュー・プルダウン → 枠の割り直し → タブの運び → 確認ダイアログ → 最後に触ったタブ）。単語詳細は閉じない。独立ウィンドウではその窓のタブを閉じる。メニューバーにいるときは元の場所へ戻る |
| Ctrl+＋ / Ctrl+－ / Ctrl+ホイール | 文字の大きさを 1 段（本文で 2px）ずつ変える。表示の設定の「文字の大きさ」と同じ値で、`settings.json` に残る |
| Ctrl+C | 単語詳細で選んだ文字をコピー |
| Tab / 矢印 | Tab は操作要素を見た目の順にたどる。検索方法・検索対象などのラジオグループには 1 回だけ止まり、中は矢印キーで選ぶ |

ブラウザのページにフォーカスがある間は、アプリのショートカットも Ctrl+ホイールも WebView2 側に取られる。
検索欄などをクリックしてフォーカスを戻すこと。

## 表示の設定

設定… の「表示」タブで、次の 4 つを選ぶ（表示 → 表示の設定… でもこのタブが開く）。このタブだけは［適用］を待たずに選んだ時点で反映し、`settings.json` に残る。

| 設定 | 選択肢 | 効き方 |
| --- | --- | --- |
| UI の倍率 | 100%〜200% | 文字・余白・ボタン・アイコンをまとめて拡大する |
| 文字の大きさ | 本文の大きさで 16〜32px（密度が「詰める」なら 14〜28px） | 文字だけを拡大する |
| 書体 | 既定（Yu Gothic UI）と、PC に入っている日本語の書体 | 本文と UI の書体。選んだ書体に無い字は既定の書体で出る |
| 密度 | 標準 / 詰める | 「詰める」は文字を小さくし行の間を詰める。ボタンの大きさは変えない |

単語ウィンドウ・単語数ウィンドウは配信用なので対象外（設定 → 単語ウィンドウ の文字サイズ倍率で変える）。

## 表示

- 配色は 設定 → 一般 で「OS の設定に合わせる」「ライト」「ダーク」から選ぶ（既定は OS の設定に合わせる）。反映は再起動後
- ステータスバーは知らせが変わるたびに一瞬光る。失敗の知らせは赤く光る。Windows の「アニメーション効果」を切っていると、
  成功は光らせず、失敗は赤を 1 秒だけ出す
- 検索モードは前方 / 部分 / 後方 / 完全、検索対象は見出し語 / 訳語 / 両方 / 全文（タグ・内容・変化形・関係を含む）
- 同音異義語は `form (2)` の形で番号を付ける
- 同じ品詞の訳語はカンマ区切り（`［名詞］犬, 狗`）
- Heksa フォントを取り込むと、検索欄・見出し語・変化形・関連語・綴り欄・語源欄のイジェール語部分がイジェール文字で描かれる
  （語源欄の判定は [データと設定ファイル](data.md#語源欄の描き分け)）
