# 使い方

## 画面の配置

画面は「枠（タブ束）」と「枠を 2 つに割る境目」の入れ子だけでできている（Blender の画面分割と同じ考え方）。
既定は左に検索、右に単語詳細。

- 検索・単語詳細・ブラウザ・ツール類・エディタ・設定など、画面はすべて 1 枚のタブ。
  同じ枠に入れたものはタブで切り替わり、別々の枠に分ければ同時に見える
- 検索と単語詳細は閉じられないが、どの枠へも運べる
- タブは非モーダル。開いたまま検索・一覧・詳細を操作できる

| 操作 | やり方 |
| --- | --- |
| 枠を割る | 枠の四隅のつまみを掴み、枠の内側へ引く。できる側が着色される。できた枠は空で、タブを運び込むまで［枠を閉じる］を出す |
| 枠を結合する | 四隅のつまみを隣の枠へ引く。消える側が着色され、中のタブは残る枠へ移る |
| 枠の大きさを変える | 境目をドラッグ |
| タブを並べ替える | 見出しを掴んで同じ枠のタブ列の上で左右へ動かす。動かしている間に並びが入れ替わる |
| タブを運ぶ | 見出しを掴んで別の枠の真ん中で離す。運び出した元の枠の端（上端はタブ列のすぐ下）へ寄せて離すと、その辺に新しい枠を割り出してから入れる |
| 独立ウィンドウにする | タブをアプリのどの窓にも掛からない場所まで運んで離す。本体の枠へ運び戻せばタブに戻る |

- 取りやめは Esc（並べ替えも元の並びに戻る）。窓の中で枠を外して（ヘッダやフッタの上で）離したときは動かない
- 割った先が 140px より細くなる分割はできない
- 最後のタブを閉じて空になった枠は隣へ吸収される（分割で作った空の枠だけはそのまま残る）
- 独立ウィンドウの中も同じ割り付けなので、枠を割ったり、窓から窓へ運んだりできる。
  窓を閉じると中のタブも閉じる（検索・単語詳細だけは本体へ戻る）。確認ダイアログは常に本体に出る
- 割り付け（枠の入れ子・取り分・タブの置き場所と並び・独立ウィンドウの位置と大きさ）は `settings.json` に残る。
  閉じたタブも次に開くと同じ枠に出る（並びの中では末尾に付く）
- 同じ種類のタブは 1 枚まで。開いている種類のボタンとショートカットは無効になる。
  単語エディタか例文エディタを開いている間は［開く］［新規辞書］も止まる（保存先が別の辞書にすり替わるのを防ぐため）

ウィンドウは標準のタイトルバーを持たない。ヘッダの空いた部分をつかんで移動、ダブルクリックで最大化する。
未保存はヘッダのドットで示す。

## ヘッダのメニュー

- **ファイル**: 開く・新規辞書・保存・別名で保存
- **ツール**: 変換（方言）・IPA → 綴り・統計・凡例・更新履歴。置き場所を覚えていないうちは独立ウィンドウで開く。
  開いているときに押し直すとそのタブを表に出す
- **ウィンドウ**: 配信用の単語ウィンドウ（選択中の単語を大きく表示）と単語数ウィンドウ（総語数を `1234語` の形で表示。
  検索の絞り込みには連動しない）。背景色・文字サイズ倍率・最前面・訳語や内容の表示可否は 設定 → 単語ウィンドウ
  （→ [OBS で映す](../README.md#obs-で映す)）
- **ブラウザ**: WebView2 のタブ。アドレス欄で Enter、URL でない語句は Google 検索。開始 URL と起動時に開く可否は
  設定 → ブラウザ

凡例は［編集］でその場で書き換えられる。`legend` が文字列か未設定なら Markdown、構造化 JSON なら JSON のまま編集する。

## 単語と例文の編集

- ［＋ 単語］、一覧の「⋯」、詳細画面のボタンから追加・編集・複製・削除。追加時は検索欄の文字列が見出し語の初期値になる
- 関連語は追加・削除とも相手側に対照の関係が自動で入る。見出し語の変更は参照側にも波及し、削除時は被参照を外す
- 単語詳細の見出し語・タグ・訳語・変化形・内容は選んで Ctrl+C でコピーできる
- ［例文］で例文の一覧・検索・追加・編集・削除。出典が「自作」以外なら ZpDIC Online に番号で照会して訳と補足を引ける
  （API キーの置き場所は [データと設定ファイル](data.md#設定ファイルと秘密情報)）
- 保存が成功するたびに `<辞書名>_changelog.csv` に更新履歴を追記する。ツール → 更新履歴 で一覧、CSV の差し替えと書き出しができる

## GitHub モード

設定 → GitHub で、辞書の編集元を「ローカル編集」と「GitHub」から選ぶ。GitHub モードでは自動保存が無効になり、
書き込みは［コミット］に一本化される。

- 対象は 1 リポジトリ・1 ブランチ・辞書 JSON 1 本・更新履歴 CSV 1 本（owner/repo/ブランチ/パスを設定で指定）
- ローカルの作業ファイルは開いている辞書そのもの。辞書を開いていないときだけ
  `%APPDATA%\ZasDictWin\github\<owner>__<repo>__<branch>\` に作る。
  更新履歴 CSV は設定で選んだ CSV、未選択なら辞書と同じ場所の `<辞書名>_changelog.csv`
- ［GitHubから読み込む］: JSON と CSV を取得して上のファイルへ上書きし、読み込み直す（上書き前に確認を挟む）
- ［コミット］: 未保存なら先に保存し、辞書と更新履歴を 1 回のコミットで送る。メッセージは保留中の更新履歴から
  自動生成され、送信前に書き換えられる
- 他所が先にブランチを進めていた場合はコミットが弾かれる。［GitHubから読み込む］で最新化してからやり直す

## キーボード

| キー | 動作 |
| --- | --- |
| Ctrl+O / Ctrl+S / Ctrl+Shift+S | 開く / 保存 / 別名で保存 |
| Ctrl+Enter / Ctrl+N | 検索欄の文字列を見出し語にして単語を追加 |
| Ctrl+E / Ctrl+D | 選択中の単語を編集 / 複製 |
| Esc | 上の層から 1 枚ずつ畳む（プルダウン → 枠の割り直し → タブの運び → 確認ダイアログ → 最後に触ったタブ）。単語詳細は閉じない。独立ウィンドウではその窓のタブを閉じる |
| Ctrl+ホイール | 文字サイズ倍率を 0.1 ずつ増減（0.6〜3.0）。`settings.json` に残る |
| Ctrl+C | 単語詳細で選んだ文字をコピー |

ブラウザのページにフォーカスがある間は、アプリのショートカットも Ctrl+ホイールも WebView2 側に取られる。
検索欄などをクリックしてフォーカスを戻すこと。

## 表示

- 検索モードは前方 / 部分 / 後方 / 完全、検索対象は見出し語 / 訳語 / 両方 / 全文（タグ・内容・変化形・関係を含む）
- 同音異義語は `form (2)` の形で番号を付ける
- 同じ品詞の訳語はカンマ区切り（`［名詞］犬, 狗`）
- Heksa フォントを取り込むと、検索欄・見出し語・変化形・関連語・綴り欄・語源欄のイジェール語部分がイジェール文字で描かれる
  （語源欄の判定は [データと設定ファイル](data.md#語源欄の描き分け)）
